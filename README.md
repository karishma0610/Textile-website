# Textile-website
Create a premium luxury website for a handloom carpet manufacturing company named “JAGDISH HANDLOOM CARPETS”, established in 1995 by Jagdish Chaurasiya. The company is based in Panipat/Punjab, India, and specializes in handcrafted carpets, rugs, dhurries, and wholesale textile production.

The website should have a modern luxury aesthetic with earthy tones such as cream, beige, warm brown, rust, and gold. Use elegant typography with serif headings and clean sans-serif body text. The overall feel should be premium, traditional, handcrafted, and trustworthy — inspired by luxury interior and artisan textile brands.

Design Requirements:

* Fully responsive for desktop, tablet, and mobile
* Smooth scrolling navigation
* Modern animations and hover effects
* Soft shadows, rounded cards, glassmorphism navbar
* Full-width hero section with a large carpet background image
* Background images should use:
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
* No white gaps or repeated background images
* Clean spacing and elegant section layouts
* Use HTML, CSS, and optional JavaScript only

* Use CSS variables for colors
* Elegant luxury typography
* Smooth hover transitions
* Grid layouts
* Mobile responsive media queries
* Professional premium UI design
* Use animations like fade-up and hover lift effects
* Use object-fit: cover for all images

Technical Notes:

* Ensure all images perfectly fit containers without repeating
* Hero image must cover the entire screen width and height
* Use:
  min-height: 100vh;
  background-size: cover;
  background-position: center;
* Add scroll-behavior: smooth;
* Use semantic HTML5 structure
* Add modern CSS animations and responsive design
